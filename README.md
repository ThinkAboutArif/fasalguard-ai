\# FasalGuard AI

AI-Powered Pest \& Disease Detection for KPK Crops, Pakistan.

\## Crops Covered

\- Wheat

\- Maize

\- Cotton

\- Tomato

\## Classes Detected

1\. Healthy

2\. Tomato Early Blight

3\. Tomato Late Blight

4\. Tomato Yellow Leaf Curl Virus

5\. Maize Common Rust

6\. Maize Northern Blight

7\. Wheat Rust (Yellow)

8\. Aphid

9\. Spider Mite

10\. Cotton Leaf Curl Virus

\## Setup (Laptop)

1\. Install Python 3.10

2\. Create virtual environment: `py -3.10 -m venv fasalguard\_env`

3\. Activate: `fasalguard\_env\\Scripts\\activate`

4\. Install libraries: `pip install -r requirements\_laptop.txt`
